# Four-UTC-week moving-block uncertainty (Loop 2, offline only)

`frontend/lib/sweep-four-week-block-uncertainty.ts` is a **predeclared descriptive sensitivity** for the completed confluence `RiskPathReport` produced by the offline 1H sweep/MSS-proxy/FVG stop-first OHLC simulation. It independently invokes the existing strict report validator before any calculations. This does not change the strategy, entry/exit rules, archived prices or execution behavior.

It retains all UTC calendar weeks from the first to the last observed entry, **including zero-trade weeks**, and samples circular contiguous blocks of **four calendar weeks**. It takes 3,000 deterministic draws with a source/configuration/seed-locked PRNG. A draw samples the same number of calendar weeks as the original span, with replacement by block; its mean is trade-weighted among the sampled completed paths. It reports descriptive 2.5th/97.5th percentiles of net bps and net R for each existing **frozen** round-trip-cost scenario. It does not add costs twice. It also reports active-week coverage and the largest four-week share of selected paths.

**Fail-closed gates:** at least 30 completed paths, 12 active UTC weeks and a 16-calendar-week span; maximum 2,600 calendar weeks; strict price/stop/target/cost/accounting and non-overlap checks inherited from `summarizeRiskPathCostRegimes`. If a resample contains zero trades, **all intervals are withheld** rather than silently dropping that draw and biasing the sampling distribution. Empty/undersized reports also withhold intervals. Fixed seed is required and bounded.

This deliberately challenges the earlier independent-week bootstrap assumption by preserving *within-block* clustering. Four weeks is a frozen arbitrary sensitivity setting, **not a data-optimized block length**. Circular wrapping can splice unrelated market regimes; four-week dependence may be wrong; serial correlation can extend beyond four weeks. Percentile ranges are **not calibrated confidence intervals**, and no p-value, out-of-sample performance, profitable edge, executable CFD fill or live-trading authorization is inferred. Historical BID/OHLC cannot establish spread, slippage, financing or broker quotes. All provenance/holdout/trading flags remain false.

Run from `frontend`: `node --experimental-strip-types --test tests/sweep-four-week-block-uncertainty.test.ts`, `npm test`, `npm run typecheck`. Tests are synthetic. Compare these ranges to the pre-existing independent-week descriptive ranges *without* choosing whichever makes a strategy look more profitable. An independently verified frozen holdout remains the responsibility of PR #29; PR #25 owns demo-fill reconciliation. No production integration or broker order route.
