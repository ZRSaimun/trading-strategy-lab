# Paired forward forecast model audit (offline, research only)

`frontend/lib/paired-forward-model-audit.ts` compares two **predeclared** model versions on exactly the same settled, fixed-phase, non-overlapping 1-, 3-, or 12-completed-candle target windows from one exact source identity. It is deliberately additive to Loop 5 PR #27 and does not change Loop 1–4 code, providers, alerts, brokers, production data or database schemas.

Call `auditPairedForwardModels(records, identity, modelA, modelB, horizon, firstBaseStart, lastBaseStart, asOf, minPairs?, maxSettlementLagSeconds?)`. Bounds must have been frozen **before** observing outcomes. Every declared slot must have both issued forecasts, a timely settlement, identical base price and identical realized direction. A missing model, void gap, unresolved or immature target, delayed settlement, conflicting outcome, mixed source, duplicate, retroactive issuance or future receipt fails closed. It never fills missing targets, cherry-picks only settled forecasts, or pools horizons/models.

A successful descriptive report gives per-model mean Brier and log loss, **A minus B** loss differences (negative favors A *on this observed sample only*), paired counts of lower-loss forecasts, and a five-chronological-block range of mean paired Brier differences. This range is **not** a confidence interval, significance test, independence claim, or proof of calibrated predictive advantage. Sample size is at least five, default thirty; observations remain serially dependent in markets, and no multiple-testing correction or transaction costs are estimated. The caller-provided timestamps, source identity, issuance records, outcomes, cohort pre-registration and settlement receipts are **not authenticated**. A self-attested `REPORT` must never be shown as verified live performance or an order signal.

Local regression check (Node 22): `cd frontend && node --experimental-strip-types --test tests/paired-forward-model-audit.test.ts`. Strict TypeScript: `tsc --noEmit --strict --target es2022 --module nodenext --moduleResolution nodenext --allowImportingTsExtensions lib/paired-forward-model-audit.ts`.

**Activation / Loop 1 handoff:** provision licensed authenticated completed-candle data, source- and session-aware gap handling, server-owned receipt clocks, append-only atomic issuance and settlement with immutable pre-registered cohorts, multiworker crash recovery and independently verified alert delivery receipts. Only then evaluate genuinely prospective paired outcomes. Historical BID-only candles are not executable bid/ask quotes; no paper fills, live notifications, broker connectivity or real-money orders are activated here. Before any merge or Render deployment, reconcile main, rerun exact-head full CI, and verify production backup restoration, rollback and post-deployment health.
