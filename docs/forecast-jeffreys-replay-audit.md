# Loop 5 — exact causal Jeffreys issuer replay (disconnected)

`audit_jeffreys_causal_replay(snapshot, min_samples=30)` independently recomputes the frozen `jeffreys-utc-phase-v1-n{min_samples}` forecast probabilities from each recorded completed-candle prefix, after validating the declared journal and matching its outcome projection to a fresh `_replay`. For horizons 1, 3 and 12, only UTC-phase-aligned base candles with every intermediate completed candle present contribute a binary UP trial. A forecast must have at least the configured 30–1000 completed trials and equal the exact `(wins + 0.5) / (trials + 1)` value. No future candle may contribute to a historical forecast. This is a deterministic implementation audit, not a new prediction model or evidence of profitability.

The result counts exact matches, incorrect probabilities, premature issuances, and other model versions (excluded, not falsely verified). It reports at most 50 mismatch examples. It also reports eligible but unissued model/horizon/candle opportunities **without calling them missed forecasts**: only an independently pre-registered issuance schedule could establish that. All journal inputs, source receipts, price sides, timestamps and outcome labels remain unauthenticated. A replay match cannot prove the original events were recorded prospectively, that a model was well calibrated, or that an executable quote existed.

This module has no API route, job, credential, network, notification, paper fill, broker order or production data write. All trading and delivery permission flags are false. It must never be used to promote historical BID candles to live executable quotes or to authorize a broker submission. Run `cd backend && PYTHONPATH=. pytest -q tests/test_forecast_jeffreys_replay_audit.py`.
