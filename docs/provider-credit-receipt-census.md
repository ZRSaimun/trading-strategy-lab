# Offline Twelve Data credit receipt coverage census

`app.provider_credit_receipt_census.audit_twelvedata_credit_receipt_coverage(db_path, utc_day=..., receipt_reports=[...])` is a **disconnected, read-only** preflight. It matches every local reservation in a quiescent, privately owned SQLite daily credit ledger to caller-supplied one-shot receipt reports from `review_twelvedata_completed_m1`. It rejects duplicate, orphaned, misidentified, malformed, misdated, or forged-live reports. Reservations without a receipt are **uncertain chargeable attempts**, never automatically refundable. Missing provider credit headers also force `REVIEW_REQUIRED`.

The function runs the existing full ledger integrity audit, opens the quiescent ledger using SQLite `mode=ro&immutable=1`, and repeats the full audit to reject a changed ledger fingerprint. Do **not** run on an actively written ledger or ephemeral Render storage. The caller must privately retain receipt reports; this function does not store or independently authenticate them. It emits only bounded counts and the ledger digest, never request IDs, secrets, raw prices or HTTP bodies.

**Interpretation:** `LOCAL_COVERAGE_ONLY` is not provider billing reconciliation or proof of vendor authentication. A caller could fabricate receipts; other API keys and apps can consume account credits. Header totals do not establish the reset window, plan entitlement, legal storage/display rights, exchange session coverage, executable BID/ASK, or trading permission. The status is deliberately limited to the *local reservation population at the audited instant*. It is not a production activation gate by itself.

Twelve Data officially describes the `api-credits-used` and `api-credits-left` response headers and a separately billable `/api_usage` endpoint: https://support.twelvedata.com/en/articles/5713553-control-over-api-usage. This module does not call either endpoint, infer resets, or incur API credits. Trading 212's official API (https://docs.trading212.com/api) currently documents Invest/Stocks ISA, **not CFDs**.

Activation remains blocked on owner-authenticated staging, independently verified plan/instrument entitlements and retention rights, a durable private ledger, independently verified UTC trading calendars, and proven production backup restoration, rollback and health checks. No live feeds, schedulers, broker accounts, orders, paid requests or production writes are introduced.
