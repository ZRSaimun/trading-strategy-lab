# Development-only candidate cost-stress audit

`app.development_cost_stress.audit_development_cost_stress(archives, observations, protocol, folds, candidates, registration, trials, selection, receipts, stresses)` is an **offline, no-order, no-network** companion to the draft Loop 3 development candidate census. It reruns the upstream source-isolated walk-forward and candidate-selection checks, not trusting a caller-supplied audit summary. Validation and untouched holdout outcomes are never read.

Each of the exact candidate × development-fold trials must have exactly one declared monetary receipt with the matching archive lineage/source digest, test-set digest, provider, venue, instrument, account alias and settlement currency. All amounts are bounded, exact-decimal strings; spreads, slippage, commissions and FX conversion charges are nonnegative. Financing is **signed** (positive debit, negative credit). Receipts must be declared as recorded no earlier than the trial's observation time and no later than the selected candidate's decision time. Each receipt includes a declared statement SHA-256, which does **not** authenticate a broker statement. Missing/duplicate rows, mixed currencies/accounts, unavailable charges, extra fields and noncausal timestamps fail closed.

The audit reports gross P&L less each explicit charge in a baseline and up to eight adverse-only stress scenarios (multipliers 1–10). Under financing stress, a positive debit increases and a negative credit shrinks in magnitude; adverse assumptions cannot mechanically improve net P&L. A deterministic **post-outcome** fingerprint binds all declared receipts and stresses. This is not a pre-outcome registration, signed source receipt, proof of full experiments, actual account reconciliation or a claim that zero costs were free.

The original candidate was selected using an unrelated **dimensionless** development score. This diagnostic does **not** retroactively reselect the strategy. A net-of-cost winner or positive declared P&L is **not** an observed tradable edge, unbiased performance estimate or evidence of statistical significance. Actual bid/ask history, broker financing and rollover calendars, cash-ledger reconciliation, execution latency/queue liquidity, FX settlement, multi-year holdout evidence and independently retained source archives remain unverified. No Trading 212 CFD order API is assumed.

Synthetic regression command (from `backend`): `PYTHONPATH=. python -m pytest -q tests/test_development_cost_stress.py`. Do not publish licensed historical archives, enable demo/live execution, or merge/deploy while production rollback and independent health checks are unverified.
