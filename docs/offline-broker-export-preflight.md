# Normalized broker-export preflight — offline only

`backend/app/offline_broker_export_preflight.py` validates a **caller-supplied canonical CSV**, not an actual broker-native format. It has no network access, brokerage API, credential handling, orders, database writes, archive publication or trading permission. A genuine broker adapter is **not** provided or implied. Trading 212 CFD API actions are not supported.

The exact CSV header is `sequence,event_id,kind,provider,venue,account_alias,instrument,position_id,order_id,currency,source_ref,effective_at_ms,posted_at_ms,side,quantity,price,signed_cash`. UTF-8 bytes and their SHA-256 must match the declared export identity. The caller must declare a positive event count, export capture clock and evaluation cutoff. The validator requires contiguous 1-based event sequence, unique IDs, a single provider/venue/account/currency, monotonic posting clocks, causal event timestamps and a captured export available by the evaluation cutoff. Strict bounded fixed-point strings prevent binary float accounting. FILL events require BUY/SELL, order ID, quantity and price, with no cash amount; COMMISSION, FINANCING and ADJUSTMENT require cash amounts and no fill fields. FX conversions are deliberately unsupported because two-leg FX settlement requires a separate authenticated specification. All event rows remain untrusted, normalized declarations.

**Do not claim historical as-of provenance merely because a broker statement was exported later.** `captured_at_ms` must be at or before `evaluation_as_of_ms`. A self-supplied checksum and contiguous row numbering do not authenticate a provider, prove that the export contains all events, establish the broker's overnight rollover calendar or validate actual executable fills. Totals are declared cash postings only, **not P&L**. A missing external receipt population remains unknown. Treat the output as a preliminary structural gate before independent read-only authenticated broker statement retrieval, signed/source-attested custody, external population reconciliation, contract-specific financing/FX and protected multi-year walk-forward evaluations.

Synthetic regression command from `backend`: `PYTHONPATH=. python -m pytest -q tests/test_offline_broker_export_preflight.py`. The preflight does not grant demo or live execution permissions. Any future live order requires an eligible documented provider/account, owner-confirmed order details, explicit caps, fresh executable quotes and securely held credentials.
