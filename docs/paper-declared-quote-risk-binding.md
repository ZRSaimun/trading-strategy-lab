# Declared quote-to-risk binding (offline only)

`inspect_declared_quote_risk_binding` combines two **caller-declared** diagnostics: `paper_declared_order_risk_preview` and `paper_declared_quote_consensus`. It checks that the exact primary quote used for order-risk arithmetic (including textual price precision, source, instrument, observation time and receipt time) is the same primary quote in the multi-feed census. It rejects quote-consensus age, transport-lag or spread policies weaker than the order-risk preview policy. A hold from either underlying validator propagates.

Invalid schemas raise `ValueError`. Disagreement returns `HOLD_QUOTE_RISK_BINDING`. A clean result is only `DECLARED_QUOTE_RISK_BINDING_UNVERIFIED`. All quote/broker authentication, source independence, stop guarantee, atomic reservation, and paper/live submission flags are **false**. This is not an API adapter, trusted broker evidence, or an order authorization. It does not call HTTP, handle secrets, persist state, submit orders, or connect to a real/paper account.

Import `inspect_declared_quote_risk_binding` from `app.paper_declared_quote_risk_binding`. Supply the existing risk-preview inputs, followed by `primary_source`, the quote-census rows and policy, and `now_ms`. The risk quote must match exactly one primary-source census row. No implicit numeric normalization: `100` and `100.00` intentionally differ to detect quote transformations.

Consistent fabricated evidence can pass: the inputs are not authenticated or independent. Risk arithmetic still omits provider contract multipliers, cross-currency conversion, guaranteed stop fills and broker financing. Production integration must bind authenticated timestamped quotes to immutable order intents, revalidate against authenticated positions, enforce atomic reservations and durable circuit breakers, reconcile protective orders and obtain positive owner approval for **each specific live order**. Trading 212's Public API does not support CFD accounts; provider and instrument eligibility must be verified before any optional adapter. No profit is guaranteed.
