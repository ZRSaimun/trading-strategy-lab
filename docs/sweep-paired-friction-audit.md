# Matched-sweep asymmetric friction sensitivity (offline research)

`auditMatchedSweepFriction` accepts the existing past-matured, UTC-hour-matched `MatchedSweepComparison`. It does **not** read prices from external vendors, send orders, certify provenance, optimize a strategy or assert a causal trading effect. It refuses missing source/seed identity, mismatched pair counts, duplicate sweep/control timestamps, future-matured controls, invalid prices, invalid direction, inconsistent gross/net price arithmetic, and altered aggregate means.

The **predeclared, immutable** grid applies extra *round-trip basis points* to each already completed hypothetical outcome: unchanged (0/0), symmetric +5/+5, sweep-only +2, +5, +10. Baseline cost is the input comparison's explicitly assumed `costBps`. The two arms have identical baseline cost. Equal extra cost cancels algebraically in the paired difference, while a sweep-only increment subtracts directly from it. Reusing the same pairs across the grid avoids outcome-dependent rematching. The function reports both event-weighted and equal-UTC-week-weighted differences; these are not independent observations. The break-even sweep-only extra cost is reported only for >=30 pairs in >=12 active weeks and a strictly positive baseline event-weighted difference; it is **not** a broker price or threshold to trade.

All values remain `DESCRIPTIVE_ONLY` even for >=30 pairs across >=12 active UTC weeks; smaller samples are `INSUFFICIENT_EVIDENCE`. No calibrated p-value, confidence interval, statistical significance, untouched holdout, or expected future return is produced. This is an additive sensitivity screen, **not** a rerun of stop/target/position-size or actual fill logic. Quote side, spread, adverse selection, financing, news, gaps, order-book depth, data licensing, UTC conventions and genuine forward execution are not validated.

For meaningful empirical use, first independently verify rights/source/timebase and run the frozen chronology/holdout plan without data snooping. Pair this screen with execution-repricing simulation and actual paper bid/ask reconciliation. Never infer a profitable CRT/ICT edge from synthetic tests or this stress table.
