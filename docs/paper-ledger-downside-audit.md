# Loop 5 — disconnected paper ledger downside audit

`frontend/lib/paper-ledger-downside-audit.ts` adds a read-only, deterministic diagnostic to the existing **offline, caller-supplied, unauthenticated** bid/ask paper journal. It replays the entire original event sequence with `replayDisconnectedPaperLedger(events, source, policy)` rather than accepting unverified precomputed performance. No order execution, broker connection, persistent storage, real quote feed or notification transport is added.

For closed trades it reports net realized P&L, gross winning/losing cash, nonannualized return on declared starting cash, median/average/worst net trade, fee total, consecutive loss streak and profit factor. Profit factor is **null** when there is no losing closed trade, not an artificial infinity; per-trade metrics are **null** with zero closed trades. Open positions remain unrealized and affect mark-to-market return and observed drawdown, not closed-trade win/loss statistics. A loss streak resets on a win or break-even trade. Return and drawdown are *not* independent validation of forecasting skill.

The observed underwater duration is measured only from the first event snapshot below the running equity peak to a subsequent recovery (or final snapshot). It is **not** the true intrabar duration, may underestimate exposure, and is based on untrusted timestamps. Neither bid/ask quotes nor events are authenticated, and no session calendars, borrow/financing, funding, liquidity or execution feasibility are modeled. JavaScript floating-point arithmetic is not suitable for actual account settlement or accounting-grade reconciliation. Outputs explicitly retain `UNVERIFIED_LOCAL_RESEARCH`, `live=false`, `quoteAuthenticated=false`, `execution=NONE`, `persisted=false`.

Synthetic regression tests: `cd frontend && node --experimental-strip-types --test tests/paper-ledger-downside-audit.test.ts`. Tests cover no-trade abstention, winner and loser costs, shorts, drawdown, losing streak, open positions, feed mismatch, stale/crossed quotes and deterministic replay. Do not report synthetic test fixtures as a forward performance record.

**Loop 1 handoff:** Authenticate prospective two-sided source quotes, bind immutable server receipt timestamps, enforce market-session/expiry rules and implement transactional append-only quote/order events with concurrent-worker crash/replay verification. Only then evaluate independent forward-demo metrics. Historical BID-only candles are not executable quotes. Any real-money order requires owner confirmation for that exact order and verified broker/account/quote/risk gates.
