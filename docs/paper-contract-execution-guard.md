# Offline contract-grid and stressed-risk review

`backend/app/paper_contract_execution_guard.py` is a **pure, disconnected, read-only** structural evaluator. It is not wired into FastAPI, an execution engine, a paper broker, or a credential store. Its inputs are untrusted caller declarations. Even if all checks pass, it returns `HOLD_RECONCILIATION` and both execution flags are `false`.

The evaluator rejects malformed/extra fields and floating-point money, checks quantity min/max and exact step multiples, price/stop tick multiples, declared minimum stop distance, the stop's correct side, and whether a current executable BID (long) or ASK (short) has already breached the stop. It rejects stale/future contract specifications (one-hour review window), stale/future quotes (three seconds), transport lag above one second, crossed/wide spreads, inconsistent contract/account currency, and unsupported Trading 212 CFD public API accounts. A contract-spec timestamp is **not** proof that a broker supplied the spec.

Risk is calculated with `Decimal` and the more adverse of the declared stressed exit or current executable exit quote, including estimated costs. It checks a maximum declared position-loss budget of 5% of equity, daily-loss budget of 10%, projected daily loss, stressed equity, existing notional/margin/reserved risk, and full cash funding for Invest/ISA-style buys. These ceilings are **review-only hard stops, not recommended allocations or broker margin rules**. For these account types, margin policy must be 100% and leverage at most 1×. SELL is withheld because no verified owned-position inventory is supplied; reducing a holding requires a separate authenticated position-aware path.

The result contains a deterministic SHA-256 diagnostic fingerprint bound to all declarations and evaluation time. It is **not** a signature, durable order-ID reservation, broker receipt, credential, approval or authorization. No execution code, provider request, API secret, migration, market data or owner account is accessed.

Official Trading 212 Public API limitations (verified 27 October 2026): https://docs.trading212.com/api/section/general-information/api-limitations . Public API is beta and documented for **Invest and Stocks ISA only**, with a demo environment and primary-account-currency restrictions; **CFD API execution is not documented as supported**. No contract tick/step values are asserted for any real instrument. This module is a future integration seam only.

Before any integration: authenticate the instrument's current contract spec and quote against the exact provider/account/instrument, verify market session and corporate actions, reconcile broker positions/working orders and stop acknowledgement, reserve order IDs and risk atomically, validate account currency and FX conversion, maintain append-only audit evidence, enforce per-order positive owner approval and re-evaluate at submission time. Actual stops may slip or gap beyond any assumed maximum loss. A fully independent release/rollback/backup gate is also required. No profit is promised.

Run isolated tests from `backend/`: `PYTHONPATH=. python -m pytest -q tests/test_paper_contract_execution_guard.py`.
