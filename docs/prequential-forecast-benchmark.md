# Loop 5: prequential forecast benchmark (offline only)

`frontend/lib/prequential-forecast-benchmark.ts` compares the last 20 (configurable 20–500) non-overlapping settled forecasts against an **adaptive Jeffreys-smoothed reference** calculated for each forecast from the preceding 20 (configurable 20–500) settled outcomes. Every reference outcome must have a resolution timestamp at or before the candidate forecast's issuance. This avoids using hindsight to construct the benchmark. The fixed UTC phase, horizon, model version and exact feed identity must match; a gap, void, late settlement, overdue unresolved forecast, duplicate, future timestamp or invalid probability fails closed rather than selectively excluding failures.

The scorecard reports mean Brier and binary log losses for model and adaptive reference, Brier skill relative to that reference, worst per-forecast excess Brier loss, and maximum consecutive forecasts underperforming the reference. The adaptive comparator is more informative than a fixed 50% guess when observed class frequencies are imbalanced, but it is not a certified optimal benchmark. Model/version/horizon and data source are never pooled.

**Research limits:** Inputs and clocks are caller-supplied and unauthenticated. This module does not connect to production, persistent storage, a broker, a quote feed, alert transport, or paper/live execution. It reports `UNVERIFIED_LOCAL_RESEARCH`, `live=false`, `persisted=false`, `execution=NONE`. Synthetic tests do not establish real-market predictive skill, calibrated probabilities, statistical significance, net trading expectancy, spreads, slippage, financing, drawdown or profitability. Correlation, changing regimes, selection into forecast issuance and delayed observations can distort these descriptive scores. No automatic trades or notifications are permitted.

Run locally: `cd frontend && node --experimental-strip-types --test tests/prequential-forecast-benchmark.test.ts`.
