# Loop 3: offline event-level CFD cash-reference audit

`backend/app/declared_event_reference_audit.py` extends the financing → execution-cost → as-of FX → rounding → split-ledger → category-anchor audit chain. It re-runs upstream checks, then requires one distinct caller-declared reference per ledger event ID, matched on position, component kind, provider, venue, account, currency, posting and receipt times, exact amount and statement SHA-256. A complete reference-event census must agree with the declared per-position/per-kind ledger census; a reference captured before its purported receipt or after the evaluation cutoff is rejected. The SHA-256 policy fingerprint binds the full reference declaration and upstream component-policy digest. Comparisons are deterministic and order-independent; no input is mutated.

This specifically catches two same-category commission entries changed in opposite directions that preserve the category total and net cash. Missing or extra IDs, mismatched fields and incomplete upstream audits withhold net cash. Only exact-decimal strings within the configured reporting minor units are accepted; invalid schemas, times, identities, excessive populations and policy fingerprints fail closed.

**Evidence limits:** The ledger, source identity, source statement hash, capture time, reference-event population and policy digest are *caller-declared*. A matching digest is not a digital signature, independent source authentication or preregistration. Coordinated changes to the reference and ledger, omitted broker positions outside the manifest, reused/fabricated broker IDs, incomplete statements, incorrect contract multipliers and broker-specific fee/FX/financing rounding can evade this audit. The synthetic 25.90 USD integration fixture is not historical performance. No executable spreads, live fills, broker connectivity, untouched multi-year holdout or trading edge is verified. The module is **offline and disconnected**, always returns `may_execute_order: false`, and never places paper or live orders.
